# Propuesta web TEYCHU

Landing page informativa desarrollada a partir del documento corporativo de INVERSIONES TEYCHU, C.A.

## Vista local

```powershell
npm run dev
```

Abrir `http://127.0.0.1:4173`. No requiere instalar dependencias.

## Verificación

```powershell
npm test
```

## Próximo despliegue a Vercel

Cuando la versión local esté aprobada, se puede desplegar directamente la carpeta estática `dist` con Vercel CLI. El proyecto todavía no está enlazado ni desplegado en Vercel.
